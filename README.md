# shate_gallery

Публичный сайт-галерея картин художника Татьяны Шмакова (SHATE ART). Статичный фронтенд, данные галереи хранятся в JSON, деплой через git.

## Структура

| Файл / Папка | Назначение |
|---|---|
| `index.html` | Главная страница: навигация, галерея, блок «Обо мне», форма обратной связи |
| `script.js` | Логика сайта: загрузка данных из `data/gallery.json`, рендер карточек, модальные окна (галерея, описание, видео), защита от копирования, форма обратной связи через EmailJS |
| `style.css` | Стили: сетка галереи, карточки, модалки, тёмная тема, адаптив |
| `data/gallery.json` | Источник данных галереи — массив объектов (название, описание, детали, longDescription, пути к картинкам, videoSrc). Добавление/редактирование картин происходит правкой этого файла |
| `update_gallery.py` | Утилита для массового обновления описаний и деталей картин. Запускается из терминала, обновляет `data/gallery.json` |
| `pictures/` | Статичные изображения: лого, фото художника |
| `paintings/` | Картинки картин. Каждая картина — отдельная папка с основной картинкой и дополнительными (interior) |
| `video/` | Видео-презентации некоторых картин |

## Как добавить картину

1. Создать папку `paintings/<название>/`
2. Положить основную картинку как `<название>1.jpg` и дополнительные как `<название>_interior1.jpg` и т.д.
3. Добавить объект в `data/gallery.json` (пример ниже)
4. Закоммитить и отправить в репозиторий

Пример объекта в `data/gallery.json`:
```json
{
    "title": "Название",
    "description": "Краткое описание для карточки",
    "details": "Холст, масло. 60×80 см.",
    "longDescription": "Полное художественное описание",
    "alt": "Альт-текст",
    "image": "paintings/name/name1.jpg",
    "galleryImages": [
        "paintings/name/name1.jpg",
        "paintings/name/name1_interior1.jpg"
    ]
}
```
